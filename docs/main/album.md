# albumnes

## Introduccion
es una pantalla que muestra las canciones de un artista que pertenecen a dicho album, te aparece la imagen y titulo del album, artista propietario, artista colaborativo, fecha publicacion, numero de canciones y duracion total de escucha, lista de las canciones y otros albumnes de interes relaccionado
